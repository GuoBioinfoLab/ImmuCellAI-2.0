# Figure 3 input data

Raw benchmark data are obtained from their public source records and are not
duplicated here. Put local copies under the configured `work_dir` as follows.

## Xu PBMC cohort: GSE107019

Place these files in `input_dir`:

- `result_tpm.csv`: gene-by-sample TPM matrix;
- `GSE107019_celltypeRatio.csv`: flow-cytometry-derived cell fractions;
- `GSE107019_sampleID.csv`: bulk-to-truth sample identifier mapping.

Some historical scripts and output directories call this cohort
`GSE107011`. This is a legacy filename only; the Xu cohort analyzed in panel A
is GSE107019.

## Alizadeh/Newman PBMC cohort: GSE65133

Place these files under
`work_dir/Fig2/Newman_Monaco_7tools_validation/RNA_Sieve_newman_pbmcs/`:

- `newman_bulk_data.txt`;
- `newman_true_props.csv`.

The truth table contains experimentally measured flow-cytometry proportions.

## Larbi/Monaco PBMC cohort: GSE107011

Place these files under
`work_dir/Fig2/Newman_Monaco_7tools_validation/RNA_Sieve_monaco_pbmcs/`:

- `monaco_bulk_data.txt`;
- `monaco_true_props.csv`.

The truth table contains experimentally measured flow-cytometry proportions.
The preparation script removes a terminal `_PBMC` suffix before aligning
sample identifiers.

## Tumor-cohort summary inputs

Panel E also uses the per-cell-type metric tables generated by
`benchmarks/fig2/` for GSE146771, GSE164522, and GSE176078. Set
`fig2_results_dir` to the directory containing:

```text
GSE146771/all_methods_per_celltype_metrics.txt
GSE164522/all_methods_per_celltype_metrics.txt
GSE176078/all_methods_per_celltype_metrics.txt
```

Do not substitute single-cell-derived pseudo-bulk proportions for the PBMC
flow-cytometry truth tables. The two validation categories have different
ground-truth sources.
