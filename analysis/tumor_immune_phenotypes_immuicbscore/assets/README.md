# Method-diagram background assets

These PNG illustrations are inputs to the archived Figure 4 method-diagram R
scripts, not expression data or statistical results. Copy the required file to
`<LOCAL_R_ROOT>/Fig4/Unified_ICB_score_cluster_ICB_integration/` before running
the corresponding prepared script:

- `Unified_ICB_score_method_GPT_image_material.png`: original diagram variant.
- `Unified_ICB_score_method_GPT_image_material_less_pies.png`: later variant.
- `Unified_ICB_score_method_GPT_image_material_detailed_RF.png`: fallback for the later variant.

The final submitted panel contains editorial layout changes, so these scripts
and assets reproduce source diagram exports, not necessarily the final composite.
