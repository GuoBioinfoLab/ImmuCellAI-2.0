# ImmuCellAI 2.0 algorithm

## Model inputs

For gene `g = 1,...,G`, sample `n = 1,...,N`, and immune state
`k = 1,...,K`, let `x_gn` denote the bulk expression abundance and `R_gk`
the reference expression abundance. The current atlas contains `K = 53`
immune states. Reference columns are normalized over genes:

```math
\phi_{gk}=\frac{R_{gk}+\epsilon}
{\sum_{h=1}^{G}(R_{hk}+\epsilon)}.
```

Each bulk sample is converted to a fixed pseudo-count depth `D = 100,000`:

```math
y_{gn}=\operatorname{round}\left(
D\frac{x_{gn}}{\sum_h x_{hn}}
\right).
```

This operation preserves within-sample composition; it does not convert TPM to
observed sequencing counts.

## Deterministic responsibility update

At iteration `t`, the expected responsibility of cell state `k` for gene `g`
in sample `n` is

```math
r_{gnk}^{(t)}=
\frac{\theta_{nk}^{(t-1)}\phi_{gk}^{(t)}}
{\sum_{j=1}^{K}\theta_{nj}^{(t-1)}\phi_{gj}^{(t)}}.
```

Here, `theta_nk` is the current immune fraction. Expected latent state counts
replace stochastic allocations:

```math
c_{nk}^{(t)}=\sum_{g=1}^{G}y_{gn}r_{gnk}^{(t)}.
```

The corresponding monitoring log-likelihood is

```math
\ell_n^{(t)}=\sum_g y_{gn}\log\left(
\sum_k\theta_{nk}^{(t-1)}\phi_{gk}^{(t)}
\right).
```

The implementation is in `expected_state_counts()` in
`R-package/ImmuCellAI2.0/R/model.R`.

## Hierarchical posterior-mean update

Each state `k` follows a path consisting of a major branch `l(k)`, subtype
`s(k)`, and terminal state `k`. Expected counts are aggregated at each level.
For a major branch `l`,

```math
C_{nl}^{(t)}=\sum_{k:l(k)=l}c_{nk}^{(t)},
```

and its posterior mean is

```math
\widehat{\theta}_{nl}^{(t)}=
\frac{\alpha_L\pi_l+C_{nl}^{(t)}}
{\alpha_L+\sum_{l'}C_{nl'}^{(t)}}.
```

Within major branch `l`, subtype posterior means are

```math
\widehat{\theta}_{ns\mid l}^{(t)}=
\frac{\alpha_S\pi_{s\mid l}+C_{ns}^{(t)}}
{\alpha_S+\sum_{s':l(s')=l}C_{ns'}^{(t)}}.
```

Within subtype `s`, state posterior means are

```math
\widehat{\theta}_{nk\mid s}^{(t)}=
\frac{\alpha_K\pi_{k\mid s}+c_{nk}^{(t)}}
{\alpha_K+\sum_{j:s(j)=s}c_{nj}^{(t)}}.
```

The terminal fraction is the product along the path:

```math
\theta_{nk}^{(t)}=
\widehat{\theta}_{n,l(k)}^{(t)}
\widehat{\theta}_{n,s(k)\mid l(k)}^{(t)}
\widehat{\theta}_{nk\mid s(k)}^{(t)},
```

followed by normalization over the `K` terminal states. The manuscript values
are `alpha_L = 10`, `alpha_S = 5`, and `alpha_K = 1`.

When no custom prior is supplied, prior mass is distributed equally among
major branches, equally among subtypes within each branch, and equally among
states within each subtype. This avoids giving branches with more annotated
states greater prior mass merely because they contain more labels.

The implementation is in `posterior_mean_theta_hierarchical()` in
`R-package/ImmuCellAI2.0/R/model.R`.

## Targeted cell refinement

In the manuscript configuration, CD4 and CD8 T-cell states share internal
hierarchies. CD4 states are organized into naive, memory, helper, Tfh, Treg,
and Tr1 groups; CD8 states are organized into naive, memory, cytotoxic, and
exhausted groups. MAIT, NKT, gamma-delta T cells, and all non-CD4/CD8 immune
states remain independent top-level branches. This confines hierarchical
shrinkage to biologically close T-cell states and avoids forcing unrelated
myeloid, B-cell, NK, granulocyte, or dendritic states to share a prior branch.

The exact mapping is generated by `create_tcell_only_53_hierarchy()` in
`R-package/ImmuCellAI2.0/R/hierarchy.R` and is written with every result.

## Convergence

After every update,

```math
\Delta_n^{(t)}=\max_k
\left|\theta_{nk}^{(t)}-\theta_{nk}^{(t-1)}\right|.
```

Iteration stops when `Delta < 1e-6` or after 50 updates. The algorithm returns
the final posterior mean rather than MCMC draws.

## Optional residual state

When `add.unknown = TRUE`, an additional latent state `u` is appended and takes
part in the same responsibility normalization:

```math
r_{gnu}^{(t)}=
\frac{\theta_{nu}^{(t-1)}\phi_{gu}^{(t)}}
{\sum_{j=1}^{K+1}\theta_{nj}^{(t-1)}\phi_{gj}^{(t)}}.
```

It is represented as a singleton branch. Its profile can be updated from the
residual expression under guarded fallback rules. UNKNOWN is a numerical
residual, not an immune-cell label. It is disabled in the principal manuscript
analyses.
