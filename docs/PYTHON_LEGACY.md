# Historical Python implementation

The former Python Gibbs/MCMC implementation is not distributed in the current
repository because it does not implement the deterministic variational
Bayesian algorithm described in the ImmuCellAI 2.0 manuscript.

For manuscript reproduction and new analyses, use the supported R package
under `R-package/ImmuCellAI2.0/` and the `run_immucellai2()` entry point.
